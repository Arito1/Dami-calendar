# Календарик Dami 🐷📚

Пары, домашки, дедлайны, экзамены и личные планы в одном месте. Сделано для телефона: ставится иконкой на экран «Домой» и работает без интернета.

## Как устроено

```
public/                 сайт (без сборки, чистый JS)
  js/data.js            модель данных и слияние версий
  js/sync.js            вход, localStorage, синхронизация с сервером
  js/app.js             интерфейс
  sw.js                 офлайн-режим
server/core.mjs         API: регистрация, вход, хранение JSON
netlify/functions/api.mjs   API на Netlify (данные в Netlify Blobs)
dev-server.mjs          локальный сервер (данные в data/db.json)
```

Каждый пользователь хранится как один JSON-документ. Пароли хешируются (scrypt).

## Запуск на компьютере

```bash
npm install
npm run dev
```

Откроется на http://localhost:8889. Локальные данные лежат в `data/db.json` (в git не попадают).
