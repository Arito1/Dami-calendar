# Календарик Dami 🐷📚

Пары, домашки, дедлайны, экзамены и личные планы в одном месте. Сделано для телефона: ставится иконкой на экран «Домой», работает без интернета и присылает напоминания.

## Что умеет

- **Сегодня.**
  - Полоска недели с цветными точками. Свайп по полоске листает недели, по ленте — дни.
  - Рядом с датой подписано, чётная неделя или нечётная.
  - Лента дня: пары и дела со временем по порядку, отмечены окна между парами. У текущей пары написано «идёт · ещё 40 мин», у следующей — «через 1 ч».
  - Отсчёт до ближайших экзаменов.
  - «Горит»: просроченное и дедлайны на 3 дня вперёд.
  - Входящие для дел без даты и счётчик «закрыто за неделю».
- **Быстрый ввод.** Пишешь как в заметке, и приложение само понимает тип, предмет, дату и время:
  - «реферат по истории до пятницы»;
  - «кино завтра в 19»;
  - «зачёт по матану 15 декабря»;
  - «дз по английскому к следующей паре».

  Понятое показывается чипами, лишнее убирается одним тапом.
- **Домашка «к следующей паре».** Срок ставится сам, по расписанию предмета.
- **Дела.** Тип: домашка, дело, событие или экзамен. Есть время, напоминание, повтор (каждый день, неделю или месяц), важность, подзадачи и заметка.
  - Свайп по делу влево — «Готово».
  - Свайп вправо — «На завтра».
- **Расписание.**
  - У пары указываются тип (лекция, практика, лаба) и аудитория.
  - Пары можно чередовать по неделям: числитель и знаменатель.
  - Пару можно отменить, перенести или поменять ей время только на один день.
  - В каникулы и сессию пары не показываются.
- **Календарь.**
  - Месяц с точками дел, значками экзаменов и днями каникул.
  - Список на 3 недели вперёд.
- **Сессия.** Экзамены и зачёты с обратным отсчётом.
- **Уведомления.**
  - за 5–30 минут до пары;
  - в нужное время для дела;
  - утренняя сводка;
  - вечером — что завтра.
- Светлая и тёмная тема, выгрузка и загрузка данных в JSON.

## Как устроено

```
public/                    сайт (без сборки, чистый JS)
  js/data.js               модель: расписание, недели, дела, повторы, напоминания, слияние версий
  js/parse.js              разбор быстрого ввода по-русски
  js/sync.js               вход, localStorage, синхронизация с сервером
  js/push.js               подписка телефона на уведомления
  js/app.js                интерфейс
  sw.js                    офлайн-режим и показ уведомлений
server/core.mjs            API: регистрация, вход, хранение JSON, подписки на уведомления
server/push.mjs            отправка уведомлений и рассылка напоминаний
netlify/functions/api.mjs      API на Netlify (данные в Netlify Blobs)
netlify/functions/remind.mjs   раз в 2 минуты рассылает наступившие напоминания
dev-server.mjs             локальный сервер (данные в data/db.json)
```

Каждый пользователь хранится как один JSON-документ. Пароли хешируются (scrypt). Правки с разных устройств сливаются по записям, поэтому данные не теряются, даже если оба устройства работали офлайн.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:8889. Локальные данные лежат в `data/db.json` и в git не попадают. Там же лежат ключи уведомлений `data/vapid.json`, они создаются сами.

Тестовый аккаунт для локальной проверки: `dami-test` / `test1234`. Он существует только в локальном `data/db.json`.

Проверки разбора текста и напоминаний:

```bash
npm test
```

## Деплой: GitHub + Netlify (бесплатно)

1. Создай пустой репозиторий на github.com (например, `damical`) и отправь код:
   ```bash
   git remote add origin https://github.com/<твой-логин>/damical.git
   git push -u origin main
   ```
2. [app.netlify.com](https://app.netlify.com) → **Add new site** → **Import an existing project** → **GitHub** → выбери репозиторий. Настройки подтянутся из `netlify.toml`, жми **Deploy**.
3. **Ключи для уведомлений.** На компьютере выполни:
   ```bash
   npm run vapid
   ```
   Добавь две выведенные строки в Netlify: **Site configuration → Environment variables**. Там же добавь `VAPID_SUBJECT` = `mailto:<твоя почта>`: это требование Apple. Потом **Deploys → Trigger deploy**.
4. Имя сайта можно поменять в **Site configuration → Change site name**, например `damical.netlify.app`.
5. **На iPhone:**
   1. Открой сайт в Safari, нажми «Поделиться» → «На экран „Домой“».
   2. Открой Календарик с иконки, зайди в Настройки → «Напоминания» и разреши уведомления.
   3. Нажми «Прислать проверочное».

Дальше каждый `git push` обновляет сайт автоматически. Напоминания рассылает функция `remind`, она работает только на опубликованном сайте: её запуски видны в **Logs → Functions**.

### Закрыть регистрацию для чужих (по желанию)

В Netlify: **Environment variables** → `REGISTRATION_CODE` с любым словом. После этого для регистрации понадобится этот код.
